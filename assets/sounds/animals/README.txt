Drop real animal recordings here (.wav, .mp3 or .flac). File names pick the animal and the moment:

  wolf_warn*.wav      wolf notices you (snarl / howl)      wolf_attack*.wav     wolf bites
  bear_warn*.wav      bear growl                           bear_attack*.wav     bear roar on the swipe
  leopard_warn*.wav   leopard rasping call / growl         leopard_attack*.wav  leopard snarl
  boar_warn*.wav      boar grunts                          boar_attack*.wav     boar squeal on the charge

Add as many variants as you like (wolf_warn1.wav, wolf_warn2.mp3 ...): one is picked at random each time.
If only one kind exists for an animal it is used for both. Animals with no files keep the built-in synth sound.
Levels are normalised automatically. Keep each clip short (0.5-3 s).
